# Unity Minesweeper

A recreation of the classic Minesweeper game built in Unity using C#.

This project was developed as a personal programming challenge and an opportunity to practice game development concepts such as grid-based logic, user interface design, state management, and debugging.

## Features

* Random mine generation
* Tile reveal system
* Flag and question mark markers
* Win and loss conditions
* Mine counter
* Game timer
* Sound effects and background music
* Main menu and game restart functionality

## Technologies Used

* Unity
* C#

## Gameplay

The objective is to reveal all non-mine tiles without detonating a mine.

### Controls

* **Left Click** - Reveal a tile
* **Right Click** - Cycle through Flag → Question Mark → None
